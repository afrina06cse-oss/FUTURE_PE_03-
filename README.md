# FUTURE_PE_03 – AI SEO Blog & Content Cluster Generator

## Project Objective

This project demonstrates an AI-assisted SEO content workflow for a hypothetical local café business in Sivakasi.

The goal is to create structured SEO content using reusable prompts, keyword intent mapping, blog outlines, sample content, content clusters, internal linking strategies, and quality checks.

## Business Context

* Business Type: Local Café
* Location: Sivakasi
* Target Audience: Local residents, students, families, and visitors
* Primary Keyword: cafes in Sivakasi

## Tools Used

* ChatGPT
* GitHub
* Markdown

## Workflow

1. Define the business type, location, audience, and content goal.
2. Map primary and secondary keywords to search intent.
3. Create an SEO-friendly H1–H3 blog outline.
4. Generate a sample SEO blog using approved content rules.
5. Create a pillar page and supporting content topics.
6. Plan relevant internal links.
7. Review content for accuracy, readability, local relevance, and publish readiness.
8. Verify local business details before publication.

## Repository Structure

* `prompts/seo_prompt_system.md` – Reusable SEO prompts
* `output/keyword_intent_map.md` – Keyword and search intent mapping
* `output/seo_blog_outline.md` – H1–H3 SEO blog outline
* `output/sample_seo_blog.md` – Sample SEO blog
* `output/content_cluster_internal_links.md` – Content cluster and internal-link strategy
* `output/quality_checklist.md` – Quality assurance checklist and limitations

## Important Note

This is a demonstration project based on a hypothetical café scenario. It does not use live keyword-volume data, verified café information, or real customer research.

Local business details should be verified before publishing. The project does not guarantee any specific search ranking.
