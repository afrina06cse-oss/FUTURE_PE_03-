# SEO Prompt System

## Prompt A – Keyword and Search Intent Mapping

Act as an SEO content strategist for a local business.

Business type: Local Café
Location: Sivakasi
Target audience: Local residents, students, families, and visitors
Main topic: Cafés in Sivakasi

Identify:

* One primary keyword
* Relevant secondary keywords
* Search intent for each keyword
* The type of content that best satisfies the search intent

Do not invent keyword volume, rankings, ratings, reviews, prices, or business details.

## Prompt B – SEO Blog Outline

Create a clear SEO-friendly H1–H3 outline for an article targeting the primary keyword.

The outline should:

* Answer the main reader question
* Use logical H2 and H3 headings
* Include the primary keyword naturally
* Cover practical information useful to the reader
* Avoid keyword stuffing

## Prompt C – SEO Blog Draft

Write a helpful and readable blog article based on the approved outline.

Requirements:

* Use one clear H1
* Use logical H2 and H3 headings
* Include keywords naturally
* Keep the tone simple and useful
* Do not create fake addresses, prices, opening hours, ratings, reviews, or first-hand experiences
* Clearly mark any information that requires verification
* Include a useful conclusion and call to action

## Prompt D – Content Cluster and Internal Links

Create a pillar page and supporting article topics around the main keyword.

For each supporting article, provide:

* Suggested title
* Main keyword
* Search intent
* Short description
* Suggested internal-link anchor text to the pillar page

Only suggest internal links that can point to real published pages.

## Prompt E – SEO Quality Review

Review the generated content for:

* Search intent match
* Keyword usage
* Readability
* Local relevance
* Accuracy
* Heading structure
* Internal-link relevance
* Metadata quality
* Publish readiness

Check that the content does not contain unsupported claims, fake business details, fake reviews, or invented statistics.

Mark any information that needs human verification before publishing.
